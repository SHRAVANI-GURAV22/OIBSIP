# Task 1: Iris Flower Classification

## 📌 Objective
The goal of this task is to build a machine learning model that can classify **Iris flower species** based on their physical characteristics such as sepal length, sepal width, petal length, and petal width.

---

## 📂 Files Included
- **Iris_Classification.ipynb** – Jupyter Notebook containing data analysis, visualization, model training, and evaluation.
- **Iris.csv** – Dataset used for training and testing the model.

---

## 🧠 Approach
1. Loaded and explored the Iris dataset
2. Performed data preprocessing and visualization
3. Split the dataset into training and testing sets
4. Trained a classification model
5. Evaluated the model performance using accuracy metrics


---

## ✅ Result
The model successfully classifies Iris flowers into:
- Setosa
- Versicolor
- Virginica

with good accuracy.
