# Task 2: Unemployment Analysis with Python

## 📌 Objective
The objective of this project is to analyze **unemployment trends in India**, especially focusing on the impact of **COVID-19** on employment rates across different regions and time periods.

Unemployment rate represents the percentage of unemployed individuals in the total labor force.

---

## 📂 Datasets Used
1. **Unemployment_Rate_upto_11_2020.csv**
   - Contains monthly unemployment rate data across India.
2. **Unemployment in India.csv**
   - Contains region-wise and area-wise (Urban/Rural) unemployment data.

Both datasets were sourced from **Kaggle**.

---

## 🧠 Approach
1. Loaded and cleaned both datasets
2. Converted date columns into datetime format
3. Analyzed national unemployment trends over time
4. Studied unemployment changes during the COVID-19 period
5. Performed state-wise unemployment analysis
6. Compared unemployment rates between urban and rural areas
7. Visualized trends using graphs and charts

---

## 📊 Key Insights
- A sharp increase in unemployment rate was observed during the COVID-19 lockdown period
- Significant variation exists between states and regions
- Urban areas showed different unemployment patterns compared to rural areas
