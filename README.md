# Oasis Infobyte Data Science Internship (OIBSIP)

This repository contains all the tasks completed as part of the **Oasis Infobyte Data Science Internship Program (OIBSIP)**.  
Each task focuses on applying data science and machine learning concepts to solve real-world problems.

---

## ✅ Tasks Overview

### 🔹 Task 1: Iris Flower Classification
- Built a machine learning model to classify iris flower species based on petal and sepal measurements.
- Techniques: Classification algorithms, data preprocessing.

### 🔹 Task 2: Unemployment Analysis
- Analyzed unemployment data to identify trends and patterns.
- Techniques: Data analysis, visualization.

### 🔹 Task 3: Car Price Prediction
- Developed a regression model to predict car prices based on features.
- Techniques: Linear regression, feature engineering.

### 🔹 Task 4: Sales Prediction
- Forecasted sales using historical data.
- Techniques: Predictive modeling, exploratory data analysis.

### 🔹 Task 5: Email Spam Detection
- Built a model to classify emails as spam or non-spam.
- Techniques: NLP, text vectorization, classification.
