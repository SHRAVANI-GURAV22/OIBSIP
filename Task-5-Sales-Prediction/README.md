# Task 5: Sales Prediction Using Machine Learning

## 📌 Objective
The objective of this project is to predict **future sales of a product** based on advertising expenditure across different platforms such as TV, Radio, and Newspaper.

Sales prediction helps businesses optimize their advertising strategy and budget allocation.

---

## 📂 Files Included
- **Sales_Prediction.ipynb** – Jupyter Notebook containing data analysis, visualization, model training, and evaluation.
- **Advertising.csv** – Dataset containing advertising spend and sales data.

---

## 🧠 Approach
1. Loaded and explored the advertising dataset
2. Performed exploratory data analysis (EDA)
3. Analyzed correlations between advertising platforms and sales
4. Split the dataset into training and testing sets
5. Trained a Linear Regression model
6. Evaluated the model using MSE and R² score
7. Predicted sales for new advertising inputs

---
## ✅ Result
The model successfully predicts sales based on advertising expenditure with good accuracy, showing a strong relationship between ad spend and sales.
