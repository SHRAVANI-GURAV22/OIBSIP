# Task 3: Car Price Prediction

## 📌 Objective
The objective of this task is to build a machine learning model that predicts the **price of a car** based on various features such as brand, year, mileage, fuel type, transmission, and other relevant attributes.

---

## 📂 Files Included
- **Car_Price_Prediction.ipynb** – Jupyter Notebook containing data preprocessing, visualization, model training, and evaluation.
- **car_data.csv / car_data.xlsx** – Dataset used for training and testing the model.

---

## 🧠 Approach
1. Loaded and explored the car price dataset
2. Performed data cleaning and feature selection
3. Applied exploratory data analysis (EDA)
4. Split data into training and testing sets
5. Trained a regression model
6. Evaluated model performance using appropriate metrics

---

## ✅ Result
The model is able to predict car prices with reasonable accuracy based on the given input features.
