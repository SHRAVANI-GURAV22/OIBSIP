# Task 5: Email Spam Detection with Machine Learning

## 📌 Objective
The objective of this project is to build a machine learning model that can **classify emails as spam or non-spam (ham)** using Natural Language Processing (NLP) techniques.

Spam emails often contain promotional content, scams, or phishing messages. This project aims to automatically detect such emails using Python and machine learning.

---

## 📂 Files Included
- **Email_Spam_Detection.ipynb** – Jupyter Notebook containing data preprocessing, model training, and evaluation.
- **spam.csv** – Dataset containing labeled email messages.

---

## 🧠 Approach
1. Loaded and cleaned the email dataset
2. Converted text labels into numeric form
3. Applied text vectorization using TF-IDF
4. Split the data into training and testing sets
5. Trained a Naive Bayes classifier
6. Evaluated model performance using accuracy and confusion matrix
7. Tested the model on custom email messages

---

## ✅ Result
The trained model successfully classifies emails as **Spam** or **Not Spam** with good accuracy.
